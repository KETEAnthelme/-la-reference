LIMITES ET ACTIONS À EFFECTUER
- Dans la base consultée le 25/11/2026, 71 élèves étaient enregistrés, mais la table parents et la table eleves_parents étaient vides. Les téléphones des parents qui n'existent dans aucune source sauvegardée ne peuvent pas être recréés par le code seul.
- Les numéros des apprenants ne sont jamais copiés comme numéros des parents.
- À la première modification d'un dossier, le secrétariat peut saisir les coordonnées disponibles; le code crée alors la fiche parent et la relation. Les numéros parent retrouvés dans une ancienne sauvegarde peuvent être importés séparément après rapprochement fiable.
- Les migrations SQL sont conservées comme références et ne doivent pas être réexécutées sans vérifier l'état actuel de Supabase.
- La fonction bulletin-qr active en production a été consultée; elle attend le champ `periode`. Aucun déploiement de cette fonction n'a été effectué dans cette archive.
- ZIP non publié. Après publication, tester avec un compte réel : inscription, modification d'un élève, affichage des deux listes, impression de liste par classe et impression de bulletins avec QR.
