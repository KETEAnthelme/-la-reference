LA RÉFÉRENCE — MISE À JOUR DES COMPTES PARENTS

Contenu :
- app.js : rattachement automatique de l'enfant à un dossier parent existant lorsque le téléphone et l'établissement correspondent ; sinon création du dossier.
- Un compte parent actif existant est réutilisé pour les enfants suivants.
- Si aucun compte n'existe, l'application demande la création du compte via la fonction Supabase manage-access.
- L'identifiant et le mot de passe provisoire sont affichés après création. Le parent doit changer son mot de passe à la première connexion.

Publication :
- La fonction Supabase manage-access version 8 a été déployée avec succès.
- Le fichier app.js corrigé doit encore être publié sur le dépôt GitHub/Vercel pour que le site public utilise cette nouveauté.

Important : la création automatique via l'écran d'inscription nécessite que l'utilisateur connecté soit administrateur général, car la fonction manage-access conserve cette restriction de sécurité. Si le secrétariat effectue les inscriptions, l'administrateur devra activer le compte parent depuis Gestion des accès, à moins d'ajouter ensuite une autorisation limitée et vérifiée pour le secrétariat.
